# Git в IDE (PyCharm) и в терминале

VS Code в работе не используется, поэтому задание выполнено в PyCharm — у него Git встроен в IDE без расширений (аналог GitLens — Annotate with Git Blame).

## Что удобно делать в IDE
1. Смотреть изменения: окно Commit показывает список изменённых файлов, а diff открывается по Cmd+D рядом со старой версией — видно, какие строки добавлены.
2. Коммитить частично: в diff можно отметить галочками отдельные куски изменений и закоммитить только их, не трогая остальное.
3. Изучать историю: вкладка Git → Log рисует граф веток, по клику на коммит показывает изменённые файлы и позволяет фильтровать историю по ветке, автору и дате.

## Что удобнее в терминале
1. Любые операции на сервере и в скриптах: там нет IDE, а команды git (rebase -i, reflog, cherry-pick, push в несколько remote) работают одинаково везде и их можно автоматизировать.
