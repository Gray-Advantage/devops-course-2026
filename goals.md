# Цели на семестр

1. Уверенно работать с Git в терминале: ветки, Pull Request, rebase, разрешение конфликтов — без подсказок.
2. Упаковать свой учебный Python-проект в Docker-образ и запускать его через docker compose.
3. Настроить CI/CD на GitHub Actions: линтер и тесты на каждый push, автоматический деплой из main.
