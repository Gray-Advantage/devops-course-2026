# Мой пет-проект
Идея: сервис сокращения ссылок со статистикой переходов (кто, когда и откуда кликнул)
Стек: Python / Django, PostgreSQL, Docker
Цель: научиться доводить веб-приложение до продакшена — контейнеризация, CI/CD и деплой на сервер

## Сроки реализации
- Сентябрь: модели ссылок и переходов, редирект по короткому коду
- Октябрь: Docker-образ и docker compose с PostgreSQL
- Ноябрь: CI на GitHub Actions (линтер + тесты)
- Декабрь: автоматический деплой на VPS

## Статус
Идея зафиксирована, разработка ведётся параллельно с курсом.
